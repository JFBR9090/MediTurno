## Política de Versionamiento del SRS
Cada cambio funcional o de interfaz aplicado al sitio web deberá quedar reflejado en la tabla **Control de Versiones** del archivo [SRS_MediTurno.md](./SRS_MediTurno.md), incrementando la versión según corresponda:
- **MAJOR (`X.0.0`):** Cambios estructurales de arquitectura o módulos principales.
- **MINOR (`1.X.0`):** Nuevas funcionalidades, pantallas, historias de usuario o reglas de negocio.
- **PATCH (`1.0.X`):** Ajustes menores de texto, validaciones, correcciones o aclaraciones de criterios de aceptación.
